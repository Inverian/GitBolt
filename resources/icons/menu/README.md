# Menu icons

These SVGs are Google's [Material Symbols](https://fonts.google.com/icons), by
Google LLC: the Outlined style at its default settings (fill 0, weight 400,
grade 0, optical size 24), 24 px, as `fonts.gstatic.com` serves them
(`https://fonts.gstatic.com/s/i/short-term/release/materialsymbolsoutlined/<icon>/default/24px.svg`;
the same icons are in
[google/material-design-icons](https://github.com/google/material-design-icons)
as `symbols/web/<icon>/materialsymbolsoutlined/<icon>_24px.svg`).

Google licenses them under the Apache License, Version 2.0:
`resources/licenses/Apache-2.0.txt`. The attribution GitBolt's packages carry is
`resources/licenses/material-symbols.txt`; `resources/licenses/SOURCES.md` says
where each text comes from.

**Modified by GitBolt.** Every file here was recoloured, and changed in no
other way: GitBolt added a `fill="#rrggbb"` attribute to the root `<svg>`
element, as its first attribute. An icon added or replaced here gets the same
treatment, a row in the table below, and nothing else changed.

On 2026-11-07, with that attribute taken out, 68 of the files were
byte-identical to what `fonts.gstatic.com` served for their icon, and
`extension.svg` to the repository's file at commit
`10ecc14790612ca8fd164e3f4ffe9c16fc50d5b7` (`fonts.gstatic.com` now serves a
redrawn `extension`). Where several icon names have the same drawing, the table
gives them all.
